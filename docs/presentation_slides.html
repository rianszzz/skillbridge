Solusi Utama
Siklus Pembelajaran Tertutup (Closed-Loop Learning)
1. Bukti Otentik
Pengguna mengirimkan repositori GitHub publik, berkas gambar DKV, atau laporan PDF Pemasaran.
2. Analisis Statis & Visi
Ekstraksi sintaks, struktur proyek, dan observasi visual multimodal 2-stage tanpa mengeksekusi kode pengguna.
3. Rubrik 1.1 Berbobot
Penilaian objektif 4 kriteria berbobot. Skor akhir dihitung matematis server (bukan karangan model).
4. Rekomendasi Terarah
Maksimal 3 modul resmi industri (MDN, Next.js, GitHub Docs) yang memetakan kesenjangan terbesar secara presisi.
5. Wawancara & Kenaikan
Latihan wawancara adaptif 5 pertanyaan dari gap nyata, lalu kirim revisi untuk mengukur peningkatan (+Δ).
🎙️ Presenter Note (45 dtk): Jelaskan siklus tertutup: tidak hanya menghakimi nilai, tapi memandu belajar, menguji lewat wawancara, dan mengukur progres perbaikan.
Slide 03 / 10
Fondasi Teknologi
Arsitektur Fullstack Modern & Multi-Model AI Pipeline
FRONTEND & BACKEND API
Next.js 16.3 (Turbopack, React 19)
Menggunakan App Router dan API Routes serverless tanpa overhead microservice. Styling antarmuka responsif dan aksesibel dibangun dengan Tailwind CSS v4.
EVALUATOR TEKS & WAWANCARA
openai/gpt-oss-20b (via Groq LPU)
Mengevaluasi bukti kode, dokumen laporan, kepatuhan Rubrik 1.1 ber-anchor diskrit {0,25,50,75,100}, kutipan bukti exact, serta memandu simulasi wawancara adaptif.
OBSERVER VISUAL MULTIMODAL
qwen/qwen3.8-27b (via Groq LPU)
Arsitektur 2-stage sequential: membaca berkas gambar DKV dan mengubahnya menjadi observasi terstruktur (warna, tata letak, hierarki) sebelum dinilai evaluator teks.
DATABASE, STORAGE & AUTH
Supabase PostgreSQL & Private Storage
Isolasi data ketat via Row-Level Security (RLS), private storage bucket untuk file bukti, serta stored procedure (RPC) untuk pembatasan kuota dan cascade delete.
🎙️ Presenter Note (45 dtk): Jelaskan arsitektur terpadu Next.js + Groq LPU + Supabase. Tekankan pendekatan multi-model: vision observer terpisah dari text evaluator.

Slide 08 / 10
Keamanan & Etika AI
Tata Kelola Keamanan Data, Etika AI, dan Batasan Sistem
AUDIT KEAMANAN
28/28 Uji Keamanan Lulus (100%)
Proteksi endpoint 401 Unauthorized, verifikasi biner magic bytes (%PDF, PNG), batas ukuran 4 MB (HTTP 413), dan pemetaan rate limit 429 Retry-After.
ZERO RCE EXECUTION
Inspeksi Kode Statis Tanpa Eksekusi
Repositori GitHub hanya dibaca via REST API secara tekstual. Kode pengguna tidak pernah dijalankan di runtime server untuk mencegah Remote Code Execution.
PROMPT INJECTION DEFENSE
Normalisasi Unicode & Adversarial Filter
Menghapus zero-width characters tersembunyi. Teks manipulatif 'ignore instructions' diblokir sebelum mencapai model evaluator.
BATASAN SISTEM YANG JUJUR
Penilaian Indikatif Portofolio
Sistem mengevaluasi bukti yang diserahkan, bukan verifikasi hukum kepemilikan karya atau jaminan penerimaan kerja. PDF memerlukan text-layer.
🎙️ Presenter Note (30 dtk): Tegaskan aspek kepatuhan: 28 skenario audit keamanan lulus 100%, zero RCE, pertahanan anti-prompt injection, serta transparansi batasan sistem.
