# Skrip Demo 5–7 Menit

1. **Masalah, 45 detik:** CV dan nilai tidak membaca bukti kerja nyata.
2. **Tiga bidang, 30 detik:** GitHub untuk Informatika, gambar untuk DKV, PDF laporan untuk Marketing.
3. **Consent dan upload, 45 detik:** tunjukkan data yang dikirim, private Storage, dan batas klaim.
4. **Penilaian, 90 detik:** jalankan satu fixture sedang; jelaskan rubrik, score per kriteria, confidence, dan referensi bukti.
5. **Gap dan materi, 45 detik:** tunjukkan maksimal tiga langkah belajar dari katalog tetap.
6. **Penilaian ulang, 45 detik:** buka riwayat dan jelaskan versi model/prompt/rubrik serta hash bukti.
7. **Wawancara, 45 detik:** mulai pertanyaan dari dua gap utama.
8. **Keamanan dan batasan, 30 detik:** kode tidak dijalankan; hasil bukan verifikasi kompetensi atau jaminan kerja.
9. **Penutup, 30 detik:** siklus bukti → gap → belajar → bukti baru.

Fallback demo hanya boleh memakai hasil seed yang diberi label jelas sebagai data demo, bukan hasil live palsu.
